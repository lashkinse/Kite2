# Kite2

Сканирование в один документ: страницы с колонкой справа, выделение и поворот, сохранение в PDF, ZIP, TIFF, JPEG, PNG. Перенос [Kite](https://github.com/lashkinse/Kite) на WPF.

## Требования

| Параметр | Значение |
|---|---|
| ОС | Windows 7 SP1 и новее |
| Разрядность | x64 |
| .NET Framework | 4.8 |

## Устройство решения

```
src/Kite2.App          интерфейс на WPF
src/Kite2.Core         работа с файлами, страницами, настройками и помощником
src/Kite2.Scan         помощник захвата (отдельный процесс x86, NAPS2.Sdk)
src/Kite2.ScanProtocol формат обмена с помощником
src/Kite2.Updater      обновлятор: дожидается выхода программы и подменяет файлы
tests/Kite2.Tests      собственный минимальный каркас проверок
```

Помощник выделен в отдельный процесс и построен на NAPS2.Sdk: захват идёт по WIA через родное окно драйвера (цветность и разрешение задаёт там человек), а приложение собрано под x64 — у части старых сканеров WIA-драйверы выпущены только под x86. Отмена посылает помощнику файл-сигнал; его фоновый поток закрывает окна сессии сканера, зависший помощник закрывается принудительно.

Обмен между программой и помощником идёт файлом ответа («ключ=значение»). Журнал общий для обеих программ: `%AppData%\Kite2\logs`.

## Запуск в тестовом режиме

`Kite2-test.bat` запускает программу с ключом `--test`: страницы рисует сама программа, сканер не нужен. Ключ `--ask` включает вопрос «Сканировать ещё?».

## Сборка и проверки

```
msbuild Kite2.sln /p:Configuration=Release
tests\Kite2.Tests\bin\x64\Release\net48\Kite2.Tests.exe
```

## Обновление

При входе программа сверяется со страницей `releases/latest` репозитория: нашла более новый выпуск — скачивает архив, распаковывает в `%LocalAppData%\Kite2\Update` и запускает `Kite2.Updater.exe` из хранилища; тот дожидается выхода программы, копирует файлы версии поверх установки и запускает программу снова.

Версия задаётся в `src/Kite2.App/Kite2.App.csproj` (`<Version>`); релиз — архив `Kite2-<версия>.zip` в выпуске репозитория.

## Настройки

`%AppData%\Kite2\settings.ini` — источник сканирования; файл создаётся при первом запуске и остаётся редактируемым вручную.
