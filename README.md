# Kite2

Сканирование в один документ. Вторая версия: интерфейс на WPF.

## Что это

Приложение сканирует страницы, показывает их колонкой, позволяет править порядок
и сохраняет результат в PDF, ZIP, TIFF или JPEG.

Это перенос [Kite](https://github.com/lashkinse/Kite), где интерфейс был на Windows
Forms. Логика перенесена, а интерфейс написан заново.

## Требования к машине

| Параметр | Значение | Почему |
|---|---|---|
| ОС | Windows 7 SP1 и новее | .NET 7 и новее Windows 7 не поддерживают, поэтому проект на .NET Framework 4.8 |
| Разрядность | x64 | ImageMagick поставляется нативной библиотекой, отдельной под каждый вариант |
| .NET Framework | 4.8 | см. выше |

## Устройство решения

```
src/Kite2.Core     работа со сканером, изображениями и файлами. Здесь нет интерфейса
src/Kite2.App      интерфейс на WPF
tests/Kite2.Tests  проверки
```

## Запуск в тестовом режиме

Сканер не нужен: страницы рисует программа.

Двойной щелчок по `Kite2-тест.bat` — и программа запустится с ключом `--test`.
Тот же ключ можно добавить к exe вручную. С `--ask` после первой серии
показывается вопрос «Сканировать ещё?».

## Внешние библиотеки

| Пакет | Зачем |
|---|---|
| Saraff.Twain 1.0.33.756 | управление сканером по TWAIN |
| Magick.NET-Q8-x64 14.17.2 | обработка изображений: вписывание скана в лист, поворот, TIFF |
| iTextSharp 5.5.13.6 | сборка PDF |
| NLog 5.5.1 | журнал работы |

## Чем отличается от Kite

- Убран внешний инструмент `pnmtojpeg`: сканы читает сам ImageMagick.
- Убран DotNetZip: архив собирается средствами .NET.
- Захват идёт внутри процесса приложения, а не отдельной программой
  `Saraff.Twain.Acquire.exe`.
- В режиме «Ч/Б» сохраняются оттенки серого без отсечки по порогу и без
  однобитного сжатия CCITT.
